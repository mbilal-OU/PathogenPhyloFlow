# PathogenPhyloFlow v0.1.0

Initial public release of PathogenPhyloFlow.

## Highlights

- Modular Snakemake workflow for integrated bacterial pathogen genomics.
- Local assembly and NCBI assembly accession input support.
- Transparent reference assessment with assembly statistics and Mash distance.
- Core-SNP phylogeny with raw and recombination-aware tree retention.
- Gubbins recombination analysis with explicit before/after comparison.
- Prokka and Panaroo accessory-genome analysis.
- Optional AMR and virulence screening.
- SNP versus accessory-genome discordance reporting.
- Temporal diagnostics before optional dated-tree analysis.
- Integrated HTML and JSON reporting.
- Installable shared Python package with Python 3.11 runtime pinning.
- Unit tests, Snakemake DAG validation, public accession smoke tests, and end-to-end CI.
- Curated 10-genome *Escherichia coli* O157:H7 tutorial.
- Real CI-derived figures and committed result previews in the README.

## Validation

The release foundation passed Python unit tests, Snakemake DAG construction, public NCBI accession resolution, and a complete four-genome CI workflow run with stable-output checks.

## Interpretation scope

The included O157:H7 data are used for workflow validation and teaching. They do not represent one epidemiologically linked outbreak. PathogenPhyloFlow does not treat SNP proximity alone as proof of direct transmission.
